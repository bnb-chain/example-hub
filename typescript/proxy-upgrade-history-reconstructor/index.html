📚 About This Tool

The Proxy Upgrade History Reconstructor is a powerful tool for analyzing upgradeable smart contracts on BNB Smart Chain (BSC). It helps you track and visualize the complete upgrade history of proxy contracts.

🔍 What It Does

  • Detects proxy contract types (EIP-1967, Beacon, Custom)
  • Reconstructs complete upgrade history from blockchain events
  • Shows current implementation, admin, and beacon addresses
  • Displays all upgrade events with timestamps and transaction hashes
  • Provides detailed information about each upgrade
  • Scans multiple addresses to suggest which are proxies
  • Includes a list of known BSC proxy addresses for testing
  • Quick access to BSCScan's proxy checker tool

🔧 How It Works

The tool reads proxy storage slots (EIP-1967 standard) to detect the current implementation address. It then scans blockchain events to reconstruct the complete upgrade history, including:

  • Upgraded events
  • ImplementationChanged events
  • AdminChanged events
  • BeaconUpgraded events

💡 Use Cases

  • Security auditing of upgradeable contracts
  • Tracking contract evolution over time
  • Verifying upgrade transparency
  • Understanding proxy architecture
