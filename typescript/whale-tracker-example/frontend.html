Whale Tracker

Track large transactions and whale movements on BNB Smart Chain

What this demo does

This app monitors BSC blockchain for large transactions (whale movements) by scanning recent blocks and filtering transactions that exceed a minimum value threshold. You can track whales across the network or focus on specific addresses.

Features

  • Whale detection — Automatically identifies large transactions above a configurable threshold
  • Block range tracking — Scan specific block ranges or recent blocks
  • Address filtering — Track whales for specific addresses (optional)
  • Transaction details — View full transaction information including value, gas, and status
  • Real-time stats — See total value tracked and transaction count

How to use

  • Set the minimum whale value (default: 10 BNB)
  • Choose to track recent blocks or specify a block range
  • Optionally enter an address to track whales for that specific address
  • Click "Track Whales" to scan and display results

Why it matters

Whale tracking is essential for market analysis, monitoring large holders, detecting significant transfers, and understanding on-chain activity patterns. This tool demonstrates how to efficiently scan blockchain data to identify and analyze high-value transactions on BSC.
