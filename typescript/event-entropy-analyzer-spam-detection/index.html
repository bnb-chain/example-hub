🔍 Event Entropy Analyzer - Spam Detection

About This Tool

The Event Entropy Analyzer is a powerful tool for detecting spam patterns in blockchain events on the BNB Smart Chain (BSC). By analyzing the entropy (randomness/diversity) of event data, we can identify suspicious patterns that indicate automated spam activity.

What is Entropy?

Entropy measures the randomness or diversity in a dataset. In blockchain event analysis:

  • High Entropy: Diverse addresses and values → Legitimate activity
  • Low Entropy: Repetitive patterns → Potential spam

How It Works

The analyzer examines Transfer or Approval events from a smart contract and calculates:

  • Shannon Entropy: Measures diversity in addresses and values
  • Pattern Detection: Identifies repeated addresses, values, and sequential blocks
  • Spam Score: Combines entropy and patterns into a 0-100 spam likelihood score

Spam Indicators

  • Many events from the same address (bot activity)
  • Many events to the same address (airdrop spam)
  • Identical values across many events
  • Events occurring in sequential blocks
  • Low unique address ratio

Use Cases

  • Detect spam token transfers
  • Identify bot-driven activity
  • Monitor contract health
  • Security analysis and auditing
