BSC Chain Performance Monitoring

Live metrics from BNB Smart Chain (BSC) via JSON‑RPC

What this demo does

This app queries a public BSC RPC endpoint to compute real-time performance metrics: block height, average block time, gas price, transactions per second (TPS), and RPC latency.

Metrics explained

  • Block # — Latest block number on BSC mainnet.
  • Block time — Time between the last two blocks (seconds). BSC targets ~3s.
  • Gas price — Current gas price in Gwei (1 Gwei = 10⁹ wei).
  • TPS — Transactions per second over the last few blocks.
  • RPC latency — Round-trip time for RPC requests (ms).
  • Gas used % — Share of block gas limit used in the latest block.

Why it matters

Monitoring these metrics helps you gauge network load, finality speed, and costs before building or running apps on BSC.
