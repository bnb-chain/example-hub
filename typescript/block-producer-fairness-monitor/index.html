🔍 Block Producer Fairness Monitor

About This Demo

This tool monitors block producer fairness on the BNB Smart Chain (BSC) network. It analyzes recent blocks to detect potential imbalances in validator distribution.

How It Works

  • Fetches recent blocks from BSC
  • Identifies the producer (validator) for each block
  • Calculates distribution statistics
  • Measures fairness using Gini coefficient
  • Highlights any significant deviations

Key Metrics

  • Gini Coefficient: Measures inequality (0 = perfect equality, 1 = maximum inequality)
  • Max Deviation: Largest difference from expected block count
  • Fairness Status: Indicates if distribution is considered fair

Why It Matters

Fair block production ensures network decentralization and prevents validator concentration. This monitor helps detect potential issues with validator rotation and distribution.
