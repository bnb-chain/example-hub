AI Contract Risk Scanner

BSC · Heuristic risk analysis

This demo scans BNB Smart Chain (BSC) contracts using the BSCTrace API (MegaNode). It runs bytecode-based heuristic checks to surface common risk patterns (delegatecall, self-destruct, CREATE/CREATE2, size).

What it checks

  • Bytecode — Contract code retrieved via BSCTrace API.
  • Delegatecall / proxy — DELEGATECALL opcode; upgradeability risk.
  • Self-destruct — SELFDESTRUCT opcode; contract can destroy itself.
  • Contract deployment — CREATE/CREATE2; factory-style logic.
  • Size — Large bytecode complexity.

How to use

Enter a BSC contract address (e.g. a token or DeFi contract), then click Scan. Results show a risk score (0–100) and individual findings. This is not a substitute for a professional audit.

API key

You need a MegaNode (BSCTrace) API key. Set BSCTRACE_API_KEY in .env before running the app.
