RPC Block Explorer

Explore BNB Smart Chain blocks and transactions via JSON-RPC

What this demo does

This app connects directly to a BSC RPC endpoint to fetch and display block and transaction data. You can explore blocks by number or hash, view transaction details, and see real-time blockchain information.

Features

  • Latest block — Get the current block number on BSC mainnet
  • Block search — Find blocks by number (decimal or hex) or hash
  • Transaction details — View full transaction information including gas, value, and status
  • Block data — See block metadata, gas usage, miner, and all transactions

How to use

  • Click "Get Latest Block" to fetch the most recent block
  • Enter a block number (e.g., 35000000) or hash to search
  • Click on any transaction hash to view its details
  • Use "latest", "earliest", or "pending" as special block identifiers

Why it matters

Understanding how to interact with blockchain RPC endpoints is fundamental for building dApps, monitoring networks, and analyzing on-chain data. This explorer demonstrates standard JSON-RPC methods used across Ethereum-compatible chains like BSC.
